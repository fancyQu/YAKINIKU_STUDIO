# 页面导航与按钮反馈整理

本轮整理覆盖实时工作台、完整音频、Space 下载、API 配置、直播设置、项目预览和独立字幕窗口。

## 页面与返回

- 主页面使用同一套功能导航与“返回来源页”入口。内部链接带 `return_to`，保留项目编号、配置模块和录制列表锚点；不会在链接中保存密钥或表单内容。
- 返回入口有明确目的地，不依赖浏览器历史中恰好存在某页。直接打开预览时，直播项目默认回录制列表，导入项目默认回完整音频列表；新窗口也有返回入口。
- API 配置内部切换使用浏览器历史，支持前进、后退。切换 ASR、文字和总览保留各自草稿。
- 在直播工作台打开其他功能时保留工作台标签页，避免中断音频采集。独立字幕窗口保持精简，只增加返回工作台。
- 返回目的地只接受本机同源且已知的页面，外部网址、接口路径、凭据和未知查询字段不会成为返回地址。
- 在同一标签页导航后尽量恢复页面滚动位置。字幕跟随依旧只滚动字幕列表。

## 按钮反馈

| 操作 | 处理与结果 |
| --- | --- |
| 保存服务商、ASR、文字、直播及字幕分句 | 按钮显示处理中、阻止重复提交；失败保留输入。API 长页底部也显示结果。 |
| 重新读取设置 | 有草稿时明确确认放弃；取消不会发送重读请求，也不清空输入。 |
| 获取模型、准备本机模型 | 保留各自状态；直播配置已保存与模型准备/状态查询失败分别报告。 |
| 刷新录制、音频项目及下载任务 | 显示刷新中，结束恢复按钮；手动刷新有成功或失败提示。 |
| 导入音频、继续处理 | 提交期间阻止重复操作；区分后台已经接受与后续列表读取失败，避免误认为没有提交。 |
| 检测浏览器组件、取消下载 | 显示检测/取消中，完成后提示结果。无效回放链接显示中文错误。 |
| 回放继续处理、重新检查精修配置 | 请求去重，按钮显示处理中，失败可恢复操作。 |
| 全屏与独立字幕 | 进入、退出和 Esc 都同步按钮文字与辅助状态；弹窗被阻止时明确提示。 |

保存前的设置草稿、未提交的音频文件/项目名和进行中的上传有离页保护。后台任务锁从设置接口读取，录制预约、模型准备、字幕补全也会锁定，轮询不覆盖草稿。Space 下载列表更新不再重建已完成任务的播放器。

## 验证范围

自动化使用本地假服务覆盖返回来源安全、嵌套回跳、浏览器历史、操作反馈、重复请求、草稿保护与播放器保留。页面检查只做导航和读取，不发起录制、上传、识别、翻译或模型收费调用。
