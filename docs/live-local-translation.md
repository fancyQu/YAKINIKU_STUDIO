# 直播本机中文翻译

更新日期：2026-10-31（北京时间）。本页说明直播翻译的本机模式；环境准备见 [MLX 本机准备记录](mlx-local-setup.md)。

直播现在可选择两种翻译方式：**云端翻译**把日语文本交给保存的文字服务商；**本机翻译**使用 Apple Silicon GPU 上的 Qwen 4-bit 指令模型。两种方式都保留原始日语、字幕时间轴和录音，直播只执行一次中文翻译，不要求独立日语校对模型。

完整音频导入和录音精准校验继续使用独立配置的 **MiniMax 文件 ASR → 日语校对 → 中文翻译**。切换直播翻译方式不会修改这些文件处理配置。

## 使用步骤

1. 使用 Apple Silicon 的 `.venv-mlx` 环境启动工作台。若旧环境未安装文字推理依赖，先在项目目录执行 `.venv-mlx/bin/python -m pip install -r requirements-mlx.txt`，再重新启动本机服务；该依赖入口包含 `mlx-lm`。依赖安装成功不代表模型已经下载或加载。
2. 打开 **直播设置 → 简体中文翻译**，将 **翻译方式** 切换为 **本机翻译**。本机模式不需要 API Key，也不要求先选择云端服务商。
3. 从目录选择一个翻译模型，查看下载体积、预计运行内存和本机状态。首次可从推荐的 **Qwen3 4B Instruct 2507 · 4bit** 开始；内存较紧张时可选 **Qwen2.5 3B Instruct · 4bit**。
4. 缺少权重时，确认 **下载来源** 显示 **阿里 ModelScope（国内源）** 及仓库编号，再由你点击 **下载模型**。下载期间可查看进度或 **取消下载**；文件校验完成后显示 **已下载**。
5. 点击 **加载模型**，等待 **已就绪**。加载只使用已准备的本机文件，不会补下载缺失权重。
6. 点击 **保存直播配置**，使翻译方式和所选模型生效。下载和加载都不会改变已保存的翻译选择，关闭页面也不会替你保存草稿。云端连接和云端模型输入单独保留，之后可以切回云端再保存。
7. 确认本机日语识别模型也已就绪，回到实时工作台选择 Edge 直播标签页并开始。模型未就绪时，工作台会阻止开始并说明需要准备的步骤。

打开页面、切换模型、保存配置和开始录制均不会自动下载。当前 Qwen 翻译模型下载源为 **阿里 ModelScope（国内源）**，仅显式点击下载才会从所示仓库和固定版本联网获取权重。仓库编号可能包含 `mlx-community`，它是组织名，不能据此判断实际下载平台；平台与仓库会分别显示。下载完成不会自动加载模型、切换翻译方式或开始录音。

## 模型与内存估计

目录中的模型都为 4-bit 量化模型。下载体积以直播设置显示的固定文件清单为准；磁盘体积不能当作运行内存。

| 模型 | 模型 ID | 预计运行内存 | 选择参考 |
| --- | --- | --- | --- |
| Qwen3 4B Instruct 2507 · 4bit | `qwen3-4b-instruct-2507-4bit` | 约 3.5–5.5 GB | 默认推荐候选，仍需同机实测 |
| Qwen2.5 3B Instruct · 4bit | `qwen2.5-3b-instruct-4bit` | 约 2.5–4 GB | 内存较紧张时的折中候选 |
| Qwen2.5 1.5B Instruct · 4bit | `qwen2.5-1.5b-instruct-4bit` | 约 1.5–2.5 GB | 占用较低，复杂口语更需核对 |
| Qwen2.5 7B Instruct · 4bit | `qwen2.5-7b-instruct-4bit` | 约 5.5–8 GB | 用于质量对照，需留足内存余量 |

以上均为**估算**：按单请求、约 2K tokens 以内短上下文，包含模型权重、KV 缓存和推理运行时；**不包含 ASR 模型、macOS、浏览器或其他应用**。实际峰值受上下文、模型实现和运行环境影响，需在本机测量。16 GB 统一内存也需要为系统与 ASR 留出余量。

推荐表示首轮候选，不代表已经证明翻译最好或比云端更快。1.5B／3B 的较小体积也不能替代日语准确率检查；7B 的较大参数量不能替代实时延迟测试。

## GPU、排队与恢复

ASR 和本机文字翻译共用**同一个单线程推理 worker**：两个模型可以驻留内存，但同一时间只执行一项本机推理，防止并发 GPU 任务相互争抢。直播本机翻译只启用一个翻译 worker；云端翻译仍可同时处理最多三段网络请求。

本机模式省去了翻译网络请求，但与 ASR 共用 GPU 和统一内存，不能保证字幕比云端更快。实时超时后，正在执行的原生推理可能仍需结束；程序不会因为取消等待就并发启动另一份 GPU 推理。超出实时预算的任务保留为待补全，已接收到的录音继续保存。停止后或在项目中重试时，继续使用本场快照中的翻译方式、模型和术语表；成功译文保留。

直播录制、字幕补全、模型下载或模型加载期间，配置修改与其他模型操作受全局锁保护。取消下载仍可操作。重新打开设置页时会显示仍在进行的翻译模型下载，即使正在下载的模型与已保存选择不同，也可以取消正确的任务。

## 隐私与失败处理

- **本机翻译：** 直播音频、识别文本、少量前文与术语表均在本机处理，不发送给云端翻译 API，不需要 API 密钥。运行模型使用已下载并校验的本机文件。
- **显式下载：** 当前 Qwen 权重连接页面显示的阿里 ModelScope 国内源，从所示仓库和固定版本获取模型文件；不需要上传直播录音或识别文本。权重加载继续只读本机文件。
- **云端翻译：** 只有保存为云端方式的场次才把日语、上下文与术语交给所选文字服务商。切换回云端不会清除已下载的本机模型文件。
- **文件精修：** 点击完整音频处理或确认录音精准校验后，音频分块发送到独立配置的 MiniMax 等文件识别服务，识别文字再交给文件校对与翻译服务。本机直播模式不自动触发精修上传。

本机依赖缺失、GPU 不可用、权重不完整或翻译失败时，会显示错误并保留已有音频与日语，不会静默换成云端翻译。下载失败可以手动重试；已有但不完整的模型目录会保留并提示检查。重新读取配置前先保存需要的修改。

本页列出的内存是选型估计，未据此宣称任何模型已在这台机器上下载、预热或通过性能与准确率验收。真实验证应分别记录加载时间、ASR 与翻译排队、生成耗时、整句字幕延迟和峰值内存，并人工核对人名、数字、短应答、口语省略及 BGM 场景。
