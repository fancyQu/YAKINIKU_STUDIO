## 根因与修复

旧配置将音频和文字合并为同一个 `scope=shared` 服务商，两个模块全量保存同一连接。ASR 改动会改变 GPT 实际连接，另一标签页还会写回旧值。当前暂存配置的 ASR 指向了 GPT 网关，模型为空；文字网关还缺少 `/v1`。

`private_configuration` 现在只读展示独立模块连接：文字保留原 ID，ASR 使用稳定且避免冲突的独立编号，仅重映射文件识别步骤。打开页面不修改文件，保存时才持久化；旧页的共享／跨模块写入会被明确拒绝。

模块和单连接保存携带各模块的 `expected_revision`；同模块陈旧保存返回 409，保留浏览器草稿与密钥输入；另一模块正常保存不导致冲突。前端也拆分旧响应并独立保存。版本号和模块上下文字段不写入连接记录。

8877 已使用原数据目录正常重启，下载任务均为终态后才切换。原设置先保存为权限 0600 的备份。已实际分别点击两个模块的保存按钮并确认成功，文件导入设置读取到 MiniMax `asr-1.0` 与既有 GPT 校对／翻译路由。MiniMax 中国站使用官方 `https://api.minimax.cn/v1/speech_to_text`；文字服务保留原密钥与模型，修正 API 路径。未打印或回显任何密钥，8765 实例未停止或修改。
