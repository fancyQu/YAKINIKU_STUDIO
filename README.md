# YAKINIKU STUDIO · 烤肉台

面向 Apple Silicon Mac 和 Microsoft Edge 的本机日语音频字幕工作台。打开自己正在收听的 X（推特）直播，采集该标签页的声音，实时显示日语原文和简体中文字幕。结束后，音频与字幕分别保存在本机，可以导入剪映、Premiere、DaVinci Resolve 或 OBS 工作流。

当前发布为 **macOS 源码预览版**，运行目标是 **Apple Silicon Mac、ARM64 Python 3.12 和 Microsoft Edge**；本机验证系统为 macOS 15.8.1。Windows 与 Android 目前只有适配评估，没有可用客户端。

## macOS 首次安装

1. 安装 Microsoft Edge 和 ARM64 Python 3.12；Python 可从 [python.org](https://www.python.org/downloads/macos/) 安装，已使用 Homebrew 的用户也可执行 `brew install python@3.12`。
2. 下载源码 ZIP 并解压，或执行：

   ```sh
   git clone https://github.com/fancyQu/YAKINIKU_STUDIO.git
   cd YAKINIKU_STUDIO
   ```

3. 双击 **安装macOS环境.command**，安装经过验证的依赖组合。此步骤只安装程序依赖，不下载模型、不上传音频。
4. 双击 **启动烤肉台.command**。打开页面后，在直播设置中手动下载、加载模型，并保存所选翻译方式。

若通过 ZIP 下载后无法双击脚本，可在项目目录执行 `zsh 安装macOS环境.command` 和 `zsh 启动烤肉台.command`。终端安装命令和 FFmpeg 可选准备见 [开发指南](docs/development.md)。这是源码运行方式，尚未提供签名／公证的 `.app` 或 `.dmg` 安装包。

## 开始使用

1. 双击项目里的 **启动烤肉台.command**，保持终端窗口打开。脚本优先使用已准备的 `.venv-mlx`，随后用 Edge 打开 <http://127.0.0.1:8765>。缺少 MLX 环境时会说明原因，不会静默切换模型。
2. 点击 **直播设置**，选择本机识别模型，并选择 **云端翻译** 或 **本机翻译**。云端模式选择文字服务商和模型，连接在 **校对与翻译** 配置页管理；本机模式不需要 API Key，从目录选择 Qwen 4-bit 模型，当前翻译权重使用 **阿里 ModelScope（国内源）** 下载。直播只绑定一个翻译模型，不要求配置文件 ASR 或独立日语校对。缺少权重时，由你点击 **下载模型**，页面显示平台、仓库、大小和进度，下载期间可以取消。ASR Small 约 481 MB，Turbo 约 1.61 GB。
3. ASR 文件校验完成后，点击 **保存并加载模型**，等待「已就绪」；也可先保存配置，再从工作台 **加载并预热**。本机翻译另按 **下载模型 → 加载模型 → 保存直播配置** 操作；下载和加载都不改变已保存的翻译选择。打开页面、切换模型、保存配置和开始录制都不会自动下载。Small 是已完成本机加载验证的多语言 ASR 候选，Turbo 尚未比较，Tiny 为显式 CPU 兼容选项。选择会持久保存，页面重载不会改回 Tiny。
4. 在 **同一个 Edge 浏览器** 的另一个标签页登录 X 并播放直播。回到工作台，点击 **选择直播标签页并开始**。在系统共享窗口里由你选择 **Microsoft Edge 标签页**，选中直播并勾选 **分享标签页音频**。
5. 检查音量条有活动，即可同时查看日语原稿与简体中文。**字幕窗口** 可打开独立字幕页用于 OBS；新日语先进入逐句列表，最近完成的双语字幕保持成对显示。
6. 直播结束时点击 **结束并保存**。收到「音频已保存」后即可下载录音；未完成的字幕继续在后台补全，请保持本机服务运行。完成或部分完成会分别显示，失败段可在项目列表点击 **补全字幕**。用户自己选择音频源，程序不会自动开始另一场录制。

需要下载已结束的 X Space 回放时，打开侧栏的 **Space 下载**。首次加载本地浏览器组件后，可粘贴 Space 网页链接，在有收听权限的浏览器中捕获本场音频，再交给本机 FFmpeg 下载和转码。组件只操作本场播放录音，没有发帖、点赞或转发功能；并非所有播放器和会员回放都能自动捕获，真实回放需在加载组件后验收。安装、范围和限制见 [Space 回放音频下载](docs/space-audio-download.md)。

在已准备好 MLX 环境的本机，可直接启动：

```sh
# 在 clone 后的项目根目录执行
.venv-mlx/bin/python run.py
```

环境与权重准备见 [MLX 本机准备记录](docs/mlx-local-setup.md)，本机翻译的操作、模型与内存估计见 [直播本机中文翻译](docs/live-local-translation.md)。新机器需要 ARM64 Python、`requirements-mlx.txt` 和匹配的本地 MLX 模型权重；本机文字翻译另需要该依赖入口中的 `mlx-lm` 与对应 Qwen 权重。原 `.venv` 不能替代 MLX 环境。默认只监听本机 `127.0.0.1:8765`，`--port 8766` 可更换端口。已有服务运行时，先结束录制与补全，再正常停止原进程；双击启动脚本只会打开已有服务，不会替换运行中的旧进程。

## 导入完整音频与项目预览

配置页分为两个模块：**ASR 音频识别**管理语音服务商、语音模型和时间戳格式；**校对与翻译**管理文字服务商以及日语校对、中文翻译两个步骤的模型。进入 ASR 模块后，先添加 MiniMax 连接并选择 **MiniMax 原生语音识别** 协议，保存服务商，再选择所用连接与模型并保存 ASR 配置。MiniMax 官方语音模型 `asr-1.0` 支持日语，使用 `/speech_to_text`；不是 OpenAI 的 `/audio/transcriptions`。模型输入框不自动选择，按官方文档手动填写或从服务返回的全部模型中选择。MiniMax 的 `/models` 列表可能只包含文字模型，列表里缺少语音模型不等于不支持。

两个模块分别保留草稿、分别保存；切换模块不会丢失当前页面里的草稿。保存一个服务商只提交当前连接，保存模块只提交该模块中的连接与模型设置。旧版共用连接自动展示为独立的 ASR 和文字连接：文字保留原编号以兼容直播引用，ASR 使用独立编号，地址、密钥和已有模型保留；读取页面不写设置，下一次保存时落盘。两模块的保存版本分别检查，同模块的旧标签页不能覆盖另一页刚保存的配置；出现冲突时保留当前草稿并提示重新读取。保存失败会保留输入并显示错误，任务进行中禁止修改。草稿不写入浏览器本地存储，离开或刷新页面前需保存。

校对和翻译是两个顺序执行的文字请求。程序先保留 `ja_raw`，校对后立即保存 `ja`，再把校对后的日语交给翻译模型。翻译失败或中断后重试，只补未完成的翻译，不重复已完成的校对。原始音频、时间轴和已完成字幕保留。MiniMax、OpenAI、DeepSeek 以及自定义兼容服务可以分别保存为多个连接；厂商名称只是标识，文字和语音协议分别决定实际请求方式，不会给只有文字接口的服务假定语音能力。

文字协议支持 **OpenAI Chat Completions / OpenAI Responses / Anthropic Messages**。MiniMax 既有 OpenAI 兼容文字接口，也有 Anthropic 兼容文字接口；后者请单独添加连接，Base URL 为 `https://api.minimax.io/anthropic`，选择 Anthropic Messages 与 Bearer 鉴权，实际请求 `/anthropic/v1/messages`。Anthropic 官方连接使用 `https://api.anthropic.com` 和 `x-api-key` 鉴权。API 地址仍由用户填写，也可主动点击“使用官方地址”；不会自动改选模型或修改已有 GPT 连接。模型列表按照所选协议请求；平台未提供列表时可手填。MiniMax 语音连接独立使用 `https://api.minimax.io/v1` 和原生 `/speech_to_text`，不使用 Anthropic Messages。

配置页参考了 [Cherry Studio 服务商配置](https://github.com/CherryHQ/cherry-studio/blob/main/src/renderer/pages/settings/ProviderSettings/ProviderList/ProviderEditorDrawer.tsx)、[Open WebUI 多连接设置](https://github.com/open-webui/open-webui/blob/main/src/lib/components/AddConnectionModal.svelte) 与 [LobeHub 自定义服务商](https://github.com/lobehub/lobe-chat/blob/main/src/features/Settings/provider/features/CreateNewProvider/Content.tsx)：连接独立管理，任务分别绑定模型，支持模型获取、搜索和手动填写。密钥不回显、不存入浏览器 localStorage；修改连接域名需重新提供密钥。启用统一配置后，旧导入设置只读，避免两处设置相互覆盖。

在侧栏打开 **音频翻译**，先分别保存 **ASR 音频识别** 和 **校对与翻译** 配置，再将完整文件拖入页面或点击选择。支持 WAV、MP3、M4A、FLAC、OGG 等常见音频格式（单文件最大 8 GiB）；文件在本机解码，分块发送至所选云端语音服务识别日语，识别文本使用所选文字 API 校对并翻译为简体中文。直播使用独立设置的本机 MLX 或显式 Tiny 兼容识别，文件识别设置不会修改直播模型或翻译路由。云端识别能否提高准确率取决于模型和音频质量，音乐、多人讲话和专有名词仍建议人工校对。

语音与文字连接的 Base URL 和 API Key 分别配置，留空的连接不会使用其他连接的密钥；编辑已有连接时，密钥输入框留空会保留已保存的密钥。语音模型初始为空，点击 **获取全部模型** 后自行选择或按服务商文档填写。语音服务必须实际支持所选协议：OpenAI 兼容连接请求 `/audio/transcriptions`，MiniMax 原生连接请求 `/speech_to_text`；普通 GPT 文字模型不能直接代替文件语音识别。模型列表展示全部可用模型，不表示每一个都支持音频。旧版共用设置仅用于尚未启用统一服务商配置的安装。

响应格式需与服务商支持一致：`verbose_json` 请求分句时间戳；`srt` 使用服务返回的字幕时间；`json` 如果只返回文字，程序会明确标注字幕时间为估算，剪辑前需要调整。程序不会自动更换模型、响应格式或退回本机识别。每个云端片段约 120 秒，上传为单声道 16 kHz WAV，原文件和预览音频保留在本机。更新前创建的本机导入项目继续按原方式处理，避免将旧项目音频自动上传。

导入后可查看处理进度，完成的句子持续保存。关闭导入页面不影响已提交的后台任务，但运行程序的终端需要保持打开。为保证直播识别速度，完整音频处理与直播录制分开运行；请结束当前录制后再导入。处理中断或翻译失败后，可在项目列表点击 **继续处理**，保留已完成的结果。

在 **完整音频 → 字幕分句** 中设置每句目标字数和最长显示时间，并点击 **保存分句设置**。默认开启，目标 **24 字、最长 6 秒**；可设为 8–80 字、2–15 秒，优先按句末标点、再按停顿标点和长度拆分。分句发生在识别后、GPT 校对和翻译前，三种字幕沿用同一组时间。字数按日语识别原文计算，GPT 校对与中文翻译后的长度可能变化。关闭自动拆分则保留识别服务原始分句。

设置仅用于之后新建的导入和精准校验项目，创建时保存快照；重试继续使用项目原设置，已有音频和字幕不会自动重做。服务仅返回整段时间时，短句时间按文字比例估算并显示提示，不能代替声学对齐，剪辑前请试听核对。录制或处理期间不能修改分句设置。

点击项目的 **打开项目预览**，即可播放音频、点击句子跳到对应位置，并切换 **日语 / 中文 / 双语**。三种模式同时作用于播放字幕与逐句列表。播放时仅逐句列表内部跟随当前字幕滚动，页面保持原位；手动滚动列表会暂停跟随，重新勾选后恢复。分别下载 `ja.srt`、`zh-CN.srt`、`bilingual.srt` 供剪辑使用，原始导入音频保存在 `source.<原扩展名>`，与预览 WAV 和字幕各自独立。直播录制项目也可以打开预览。

### 直播录音精准校验

直播结束并保存后，打开该场回放预览，在 **录音精准校验** 中确认所选服务与费用，点击 **开始精准校验**。程序使用已保存的 **MiniMax 原生 ASR → GPT 日语校对 → GPT 中文翻译** 配置，从完整录音重新生成独立精修项目。这里的 GPT 可通过第三方兼容服务连接；模型由用户按服务商实际支持范围选择。缺少配置时会提供 ASR 和文字配置入口，不自动选择模型或上传录音。

原直播的音频、字幕和项目信息保持原样。多卷或不同采样率的直播录音按顺序在本机生成精修项目的 48 kHz 双声道 WAV；仅识别副本分块发送到 MiniMax。进度在原回放页持续显示，关闭页面不影响后台任务。重复点击返回同一个精修项目，失败或重启后点击 **继续精准校验** 只补未完成步骤；已完成识别、校对和成功译文继续保留。项目固定开始时的服务连接、模型与术语表，密钥仍从本机设置读取；连接地址或协议改变时暂停重试，避免无提示改变音频接收方。

完成后点击 **预览精修结果**，切换日语、中文、双语并分别下载三种 SRT。重新识别不保证全部正确；若 MiniMax 仅返回文本，仍会显示时间轴为估算的提示，剪辑前需试听核对。

## 保存位置与文件

每场直播保存到 `data/recordings/<录制编号>/`，直播标题与日期记录在 `session.json` 中。下载操作只是复制一份文件，原始文件仍在这里。

| 文件 | 用途 |
| --- | --- |
| `audio.wav` | 16 位 PCM、双声道 WAV，通常 48 kHz，可直接导入剪辑软件 |
| `audio-002.wav` 等 | 超过三小时后的连续分卷，避免 WAV 的 4 GiB 限制；每卷在时间轴上的位置见 `session.json` 的 `audio_parts` |
| `zh-CN.srt` | 简体中文字幕 |
| `ja.srt` | 日语原文字幕 |
| `bilingual.srt` | 中文在上、日文在下的双语字幕 |
| `bilingual.vtt` | 双语 WebVTT 字幕 |
| `transcript.txt` | 带时间码的日中对照文本 |
| `session.json` | 原文、译文、毫秒时间轴、分卷位置和处理状态，方便二次加工 |

字幕时间从录音的第一个采样开始计算，云端返回或翻译变慢不会使导出的时间轴后移。直播画面如果另行录制，应从同一时刻开始，或在剪辑软件中调整整体偏移。三小时分卷之间没有音频间隙，按 `audio_parts` 顺序连续放置即可；字幕保持整场时间轴。

## 实时表现与恢复

- 新直播路径为 **本机日语识别 → 一次简体中文翻译**。不再串行调用独立校对。原稿保留在 `ja_raw` 与 `ja`，翻译模型只做有依据的轻量理解，不补写漏听内容。完整音频精修仍按「ASR → 日语校对 → 中文翻译」处理。
- 以停顿约 600 ms、最长 5 秒为基线；直播设置可选 3 秒对比。Whisper 是分段识别，不是逐字流式输出。云端翻译最多同时处理三段网络请求；本机翻译使用一个翻译 worker，并与 ASR 共用单线程推理 worker，同一时间只执行一项本机推理。两个模型可以驻留内存，需共同考虑统一内存占用；本机模式不能保证比云端更快。
- ASR 与翻译队列有上限。超过实时预算的任务持久标记为待补全，新字幕优先；已保存音频区间可在停止后按顺序补回，不自动上传给 MiniMax。识别或翻译失败不阻止原始 WAV 保存。
- 每段有稳定 ID、序号和场次标识。迟到的旧译文补入历史与导出，不倒退主字幕，不把新日语和旧中文凑成一组。工作台与独立字幕窗口使用同一份显示状态。
- 停止先 flush 浏览器尾包并取得后端已接收帧数确认，再关闭音频。音频已保存与字幕补全状态分别显示。原始音频已收到而识别副本未到的尾区间也可本机补识别；未传到服务器的音频不能恢复。
- 重启将中断段的运行状态改为可恢复，并保留已接收音频。补全沿用本场的模型、翻译路由、术语与切段快照；成功段不会重复调用。原翻译连接删除、地址或协议改变、本机权重版本不符时，会提示恢复配置，不静默换服务或模型。
- 无快照的旧 Tiny 直播项目首次补全时绑定当前明确选中的直播翻译路由，保留已有校对日语和成功译文，只补缺失翻译。文件导入项目继续使用文件处理流程。
- 中文字幕只包含成功译文，错误摘要不会写入字幕。正常无语音段使用 `no_speech` / `skipped` 终态，异常空响应保留为失败，不编造句子。字幕时间来自音频累计采样数，分卷沿用整场时间轴。
- ASR 模型、短样本速度和自动化异常测试已有验证记录；尚未完成 10 分钟实际直播、30 分钟稳定性、真实网络翻译延迟及人工日语准确率验收。Small 与 Turbo 未完成对比。ASR 的测试不代表本机 Qwen 翻译已经通过性能或准确率验收。已知限制与可复现记录见 [本轮实现记录](docs/live-mlx-implementation.md)、[实际 ASR 适配器测速](docs/live-asr-runtime-validation.md) 和 [直播本机中文翻译](docs/live-local-translation.md)。
- **体验字幕演示** 只展示本地模拟文字，不调用 API、不录音，不代表真实转译性能。

## API 与隐私

新直播中，所选标签页的音频只在本机识别，不上传到 API。**云端翻译**会把识别文字、少量上下文与术语发送到直播选定的文字服务；补全缺失翻译也会发送相应日语。**本机翻译**将这些文本保留在本机，用已下载的 Qwen 权重推理，不需要 API Key，也不会在失败时自动切换云端。只有显式点击下载模型时才联网获取权重；当前 Qwen 翻译权重从 **阿里 ModelScope（国内源）** 获取，下载不上传直播音频或识别文本。仓库编号中的 `mlx-community` 是组织名，实际平台以页面的下载来源为准。

完整音频导入与用户确认后的录音精准校验仍使用独立配置的云端语音服务，会上传音频分块，识别文本继续发送到文件校对与翻译服务。目的地由所选连接决定；本机直播模式不会自动触发文件精修。录音与字幕保留在本机，原始识别文字也记录在会话数据中。浏览器只用于选择自己已有权限收听的直播，程序不需要 X 账号密码或 Cookie。

密钥仅在本机 `data/settings.json` 保存，文件权限为 `0600`；接口不会返回密钥，浏览器不使用 localStorage 保存密钥。也可通过环境变量 `OPENAI_API_KEY` 为旧共享配置提供密钥；统一服务商配置只对绑定环境密钥的连接读取该变量。本项目的 `.gitignore` 已忽略 `data/`、`.env`、`.env.*`、虚拟环境、本机验收产物和下载素材。

云端 API 的费用按服务商规则计算，ChatGPT 订阅通常不等于 API 额度。运行前请在自己的 API 账户中设置适当预算。模型访问和网络可用性取决于服务商、你的 API 账户与所在地；错误信息会提示密钥、额度或网络问题。

接口依据官方 OpenAI 文档：[实时转写](https://developers.openai.com/api/docs/guides/realtime-transcription)、[文件转写](https://developers.openai.com/api/docs/guides/speech-to-text)、[Chat Completions 与 Responses](https://developers.openai.com/api/docs/guides/migrate-to-responses)。第三方是否兼容以其实际文档和试录结果为准。

## 第三方兼容 API

**服务商连接**保存地址、密钥与协议，**业务配置**分别选择连接与模型。直播独立保存本机 ASR、`translation_backend`、`local_translation_model` 与云端 `translation_route`；切换翻译方式时保留两种模式的选择，本机模式允许云端连接为空。文件设置保留 `file_asr`、`correction`、`translation`。两条业务可复用文字连接，但不强制共用模型、术语和切段参数。修改直播配置不会覆盖 MiniMax 文件设置。

文字连接支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。地址、密钥初始为空，由用户填写；选择预设不会填入地址，需主动点击 **使用官方地址**。基础地址可保留代理前缀，不自动补 `/v1`；不要填写完整的 `/chat/completions`、`/responses`、`/messages` 或音频请求地址。远程要求 HTTPS，本机回环地址可使用 HTTP。

**获取全部模型**读取所选连接返回的模型列表，可搜索、选择或手填；列表不保证每个模型都支持文字或音频功能。读取列表不调用翻译，也不上传录音。直播翻译使用已保存的文字连接；若需修改密钥或地址，先在服务商编辑区保存，再回到直播设置重新读取。文字和语音协议以服务商实际支持为准，不能仅凭“兼容 OpenAI”假定具备语音识别。

已有连接的密钥输入框留空会保留密钥；更换域名或端口必须重新填写，避免把旧密钥发往新地址。显式移除密钥后才会清空。环境变量密钥不因保存其他设置而复制到文件；接口不回显密钥，场次快照和可下载 `session.json` 不包含凭据。旧字段保留用于兼容，已独立保存的直播设置优先于旧共用字段。

真实服务可用性、费用和数据保存规则由服务商及账户决定。读取模型成功或设置显示「已配置」都不代表真实翻译已通过测试。

## 常见问题

**跳转后如何返回：** 各功能页顶部提供“返回来源页”，同时可切换实时工作台、完整音频、Space 下载、API 配置与直播设置。配置模块支持浏览器前进和后退；有未保存修改时离页会提示，重新读取前会确认是否放弃。操作中的按钮显示处理状态，失败时保留输入；完整说明见 [页面导航与按钮反馈](docs/ui-navigation-review.md)。

**没有音频输入：** 重新共享，选择 Edge 的直播标签页并勾选分享音频。确认直播播放器已经播放且没有静音。若共享列表没有标签页，请将烤肉台页面也放在 Edge 中打开。必要时检查 macOS 系统设置里 Edge 的屏幕与系统音频录制权限，修改后重新打开 Edge。

**只有录音，没有字幕：** 查看模型状态与音量条；缺少 ASR 文件时，在直播设置手动点击 **下载模型**，完成后点击 **保存并加载模型**，等待「已就绪」。若提示 Apple GPU 不可用，确认通过 `.venv-mlx` 在普通本机环境启动。只有日文、没有中文时，云端模式检查翻译连接、模型、额度和网络；本机模式检查 `mlx-lm` 运行环境、翻译权重是否完整、是否已加载并保存配置，以及统一内存和排队状态。识别中途失效会明确显示仅录音；已有音频与日语可用于补全。

**翻译接口返回网页：** Base URL 必须填写服务商的 API 基础地址，不能填写控制台或网站首页。某些兼容服务要求包含 `/v1`，例如 `https://api.example.com/v1`（仅为格式示例，请替换为实际服务地址）。错误路径也可能返回 HTTP 200 的 HTML 网页。程序会明确提示地址问题，不自动猜测其他路径。修正连接后，旧场次的固定连接快照仍需明确重新绑定，不能绕过路由校验。

**字幕不同步：** 导出的字幕使用录音时钟。若视频比本程序早或晚开始，整体移动字幕轨道；句子内部的精确断句需要后期微调。

**想停止服务：** 先结束录制，确认保存完成，再回到启动终端按 `Control+C`。
